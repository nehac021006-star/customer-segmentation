# Customer Segmentation

## 📌 Project Overview
Customer Segmentation is a data analysis project that groups customers based on their purchasing behavior.  
This helps businesses understand customer patterns and target them more effectively.

In this project, **RFM Analysis** and **Clustering techniques** are used to segment customers into meaningful groups.



## 🎯 Objectives
- Analyze customer purchasing behavior
- Segment customers into different categories
- Identify high-value and low-value customers
- Support data-driven marketing decisions



## 🧠 Concepts Used
- Customer Segmentation
- RFM Analysis (Recency, Frequency, Monetary)
- Clustering (K-Means)
- Data Preprocessing
- Exploratory Data Analysis (EDA)



## 🛠️ Technologies & Tools
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn
- Jupyter Notebook



## 📊 RFM Analysis
- **Recency (R):** How recently a customer made a purchase  
- **Frequency (F):** How often a customer makes a purchase  
- **Monetary (M):** How much money a customer spends  

Based on RFM scores, customers are grouped into segments such as:
- Loyal Customers
- Potential Customers
- At-Risk Customers
- Lost Customers
